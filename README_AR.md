# بلوساب — الإصدار 27 (الاتصال الموحّد + التصميم الجديد)

تطبيق Flutter (أندرويد) للتواصل المباشر بين الهواتف دون إنترنت أو مودم.

## كيف يعمل الاتصال
- `lib/services/mesh_hub.dart` هو المركز الوحيد: يشغّل Bluetooth وWi-Fi Aware والشبكة المحلية **معاً وبشكل دائم**.
  كل هاتف يبث (Bluetooth قابل للاكتشاف + Wi-Fi Aware publish) ويستقبل (مسح Bluetooth دوري + Aware subscribe + مستمع) في الوقت نفسه.
- مراقب (watchdog) يعيد تشغيل أي وسيط يتوقف، ويجدّد ظهور البلوتوث، ويعيد الاتصال بالأجهزة المعروفة.
- الإرسال يختار أفضل رابط حي (Aware ثم LAN ثم Bluetooth) ويتحول للتالي عند الفشل؛ المحاولات المتكررة تُرسل عبر كل الروابط.
- خدمة أمامية (`MeshForegroundService`) تُبقي البث والاستقبال شغّالين أثناء وجود التطبيق في الخلفية.
  إغلاق التطبيق من قائمة التطبيقات الأخيرة يوقف الشبكة.

## واجهة الدخول الإلزامية
`lib/screens/startup_gate_screen.dart`: لا يُفتح التطبيق حتى تُمنح الأذونات ويُشغَّل Bluetooth وWi-Fi،
وتعود فوق التطبيق إن أُطفئ أحدهما لاحقاً.

## البحث
`lib/screens/nearby_users_screen.dart`: واجهة بحث خاصة تعرض مستخدمي بلوساب القريبين فقط (الاسم والصورة) دون نوافذ النظام.

## الضغط
- أثناء المزامنة: كل حزمة كبيرة تُضغط (gzip) إن صغُر حجمها وتُفك قبل أن تراها أي شاشة (`packet_codec.dart`).
- الملفات تُضغط قبل الإرسال وتُفك عند الاستلام.
- التخزين: الرسائل والمنشورات والقصص تُحفظ مضغوطة وتُفك عند العرض.
- فك الضغط محدود الحجم لمنع الحزم الخبيثة.
- صور JPEG وفيديو MP4 مضغوطة أصلاً فلا يقلّصها gzip كثيراً.

## التصميم
`lib/widgets/blousab_visuals.dart` يحوي عناصر التصميم المشتركة (إطارات متوهجة، شريط تنقل عائم، حلقات القصص…).
